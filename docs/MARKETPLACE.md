# 排序市场（测试）

自 0.7.0 起，默认市场连接独立 HTTPS 服务，不再使用 GitHub 登录和 PR 投稿。软件源码及程序更新仍使用 GitHub；市场账号、排序和图片由独立服务托管。旧 GitHub 协议、目录工具与兼容测试保留，不是当前默认市场。

## 浏览、账号与投稿

- 市场位于主窗口“游戏日志”右侧，首次进入展示警告，确认后按需读取目录，不在主程序启动时预取排序。匿名可浏览与下载已审核内容，搜索在已加载目录中进行。
- 使用用户名和密码注册、登录，无需 GitHub、邮箱或手机号。昵称用于市场展示，用户名用于登录和归属识别。密码为 7–15 个 Unicode 字符，不额外要求复杂度。
- 注册时的恢复码请离线保存；无邮箱或手机号找回渠道。修改密码保留原恢复码，不再次展示。使用恢复码重置账号后须保存新显示的恢复码。
- 登录后点击昵称可修改昵称、修改密码或退出。有效会话由当前 Windows 用户加密保存，按服务地址和客户端隔离；更新可恢复有效会话，但过期、撤销或换服务器后需要重新登录，不保存明文密码。
- “发布当前使用排序”捕获当前清单；“发布其他排序文件”先选择文件，再进入简介编辑。后者只读提取文件快照，不导入、不替换当前排序，不改原文件及游戏配置，也不改变未保存修改或撤销历史。
- 排序标识自动生成并由服务端保证唯一归属；未上架前隐藏，审核后可在市场详情查看。新作品版本默认 1.0，后续建议 1.1、1.2，以此类推。
- 可填写标题、简介、多个游戏版本、Steam 合集编号或链接，并上传最多三张 PNG/JPEG；简介可读取 Steam 合集资料并继续手工修改。首次发布不要求更新日志，后续更新可选填。
- “我的排序与草稿”支持右键修改/删除及双击修改；只有明确点击保存才写入本机草稿。退回稿件可修改并重新提交，待审稿件避免重复修改。原作者可删除单个版本或整份作品，不能操作别人的内容。

## 下载与应用

1. 选中条目只展示目录资料；同一排序的多个版本合并展示，默认数值最新版，也可选择旧版本及查看更新日志。点击下载后才获取相应排序文件并校验。
2. “下载排序并另存为”只保存到用户选择的新文件，不改变订阅或当前游戏排序。
3. “下载排序并使用”有绑定合集时读取合集成员，自动补订未订阅项，不逐个强制重新订阅已订阅项。没有绑定合集时先询问是否补全未订阅模组，拒绝仍可导入。
4. 右上角展示下载及 Steam 等待状态。等待下载完成或连续约 30 秒无下载活动后继续；空闲不代表全部安装。无法下载、模组缺失会跳过下载并提示，但按作者完整顺序正常导入保存。
5. 普通导入不进行自动依赖修复或改序，版本差异只提示；主界面警告和错误仍正常显示。自动排序是单独操作，不与导入混用。
6. 保存沿用游戏进程、目标路径、磁盘变化检查及备份、原子写入、撤销规则。失败或取消保留原排序；已由 Steam 接受的下载可能继续，不擅自取消其他订阅。

市场不托管模组文件或固定历史模组二进制。旧排序版本不等于能还原旧模组组合，不能把投稿审核或结构校验宣传为实际游戏兼容验证。

## 文件、权限和审核

- 排序按白名单字段重新生成 XML，不原样保存或执行任意上传文件；禁止 DTD、外部实体及超限结构。
- 每份排序版本最多三图，单张原始及重建图最多 5,242,880 字节（约 5.24 MB），边长最多 8192、总像素最多 2400 万。服务端完整校验 PNG/JPEG 后从像素重新编码，去除原文件元数据和附加内容。PNG 为 RGBA8 精度，16 位输入转为 8 位；JPEG 质量 98，不是数学无损。
- 客户端上传前自动压缩，三张合计尽量不超过 7 MB 是软目标，不暗中降低到任意画质或修改原图。服务端返回重建后长度和 SHA-256，不能假定与原始上传字节一致；下载及审核前再次校验文件。
- 游客只读已审核内容。投稿、图片、修改和删除均要求账号，并校验对象归属及状态；审核另需审核员权限。注册、登录、恢复和幂等退出保留必要匿名入口，仍受来源校验、CSRF 和限流约束。直接调用 API 不能绕过这些服务端规则。
- 独立审核助手每分钟检查，其他时间不轮询；查看和审核按需请求。不使用 AI，审核员人工判断标题、简介、图片等内容，通过后才公开。
- 排序标题、简介请勿包含政治相关内容；图片请勿包含色情或裸露内容。作者应拥有所提交资料的分发权，不包含密码、恢复码或私人资料。
- 文件重建不是病毒库查杀，无法保证解码器永无漏洞、图片中不存在隐藏信息或 Steam 模组代码安全。用户累计额度、有效账号滥用、云端攻击、证书和备份维护也有独立边界，不宣传绝对安全。

客户端来源和更新入口与市场服务相互独立；市场暂不可达时仍保留普通排序功能和可用缓存，并明确显示网络或缓存状态。
